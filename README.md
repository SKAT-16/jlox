# jlox — Crafting Interpreters

This project is my implementation of **jlox**, the tree-walk interpreter built in _Crafting Interpreters_ by Robert Nystrom.

The goal of this project is to understand the fundamental components of a programming language interpreter by implementing the Lox language from scratch in Java.

## About jlox

jlox is a tree-walk interpreter for the Lox programming language.

The interpreter is built incrementally and covers concepts such as:

- Lexical analysis and scanning
- Tokens and lexemes
- Parsing
- Abstract Syntax Trees (ASTs)
- Expression evaluation
- Statements and control flow
- Variables and lexical scope
- Functions and closures
- Static resolution
- Classes and inheritance

The general execution pipeline is:

```text
Lox Source Code
       ↓
Scanner
       ↓
Tokens
       ↓
Parser
       ↓
Abstract Syntax Tree
       ↓
Interpreter
       ↓
Program Result
```

## Project Structure

```text
jlox/
├── src/
│   └── com/
│       └── craftinginterpreters/
│           └── lox/
├── bin/
└── README.md
```

- `src` — Java source code for the interpreter.
- `bin` — Compiled Java class files generated by VS Code.
- `com.craftinginterpreters.lox` — Main package containing the jlox implementation.

## Running jlox

Compile and run the project using the Java tooling provided by VS Code.

The interpreter supports running a Lox source file:

```bash
java com.craftinginterpreters.lox.Lox script.lox
```

It can also run as an interactive REPL when started without a script.

## Learning Purpose

This project is built while working through _Crafting Interpreters_.

The focus is not on using parser generators, compiler frameworks, or external libraries. The scanner, parser, syntax tree, and interpreter are implemented manually to develop a deeper understanding of programming language implementation.
